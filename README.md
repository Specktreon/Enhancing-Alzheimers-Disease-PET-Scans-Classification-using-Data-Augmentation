# Enhancing Alzheimers Disease PET Scans Classification using Data Augmentation
This project explores the use of deep learning and data augmentation techniques to improve the classification of Alzheimer’s disease from PET brain scans. The study uses medical imaging data from the ADNI dataset and focuses on early-stage Alzheimer’s detection.  To address class imbalance and limited medical data, Generative Adversarial Networks (GANs) were used to generate synthetic PET scans for augmentation. The augmented dataset was then used to train a deep learning classifier for Alzheimer’s disease prediction.  The project includes data preprocessing, patient selection, model training, and evaluation experiments conducted in Python using Jupyter Notebook and common machine learning libraries.
